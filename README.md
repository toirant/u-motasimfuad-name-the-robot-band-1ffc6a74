## The entry

> The Blue Screens of Death Metal — hit single 'Have You Tried Turning Me Off and On Again?'

## How it works

`main.py` (Python 3, no dependencies) writes one funny robot band name plus a
few words on its hit song to `/output/entry.txt`, self-checking the entry
against the gate (1–200 characters, not only whitespace) before writing it.

Run it:

```sh
python3 main.py
```
